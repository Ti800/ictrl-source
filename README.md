# iCTRL Feather / AltStore source

Auto-generated from [OpenMinis/iCTRL releases](https://github.com/OpenMinis/iCTRL/releases) every 3 hours by GitHub Actions.

Add this URL to Feather → Sources:

    https://raw.githubusercontent.com/Ti800/ictrl-source/main/ictrl-source.json

Upstream IPAs always report version `1.0`, so each release is mirrored here with
`CFBundleShortVersionString` / `CFBundleVersion` patched to the release tag
(e.g. `1.98.12`). Feather re-signs on install, so the patched copies install normally.
